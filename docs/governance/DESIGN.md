# Design direction

Template memakai UI utilitarian yang tenang: latar netral, satu warna teks utama, border halus, radius kecil, dan hierarki berbasis ukuran/berat teks. Produk baru harus menetapkan merek, token warna, dan konten nyata sebelum memperluas halaman publik.

Setiap layout harus memiliki state mobile yang nyata. Sidebar dashboard menjadi navigasi horizontal pada layar kecil, konten grid runtuh bertahap, form tetap satu kolom, dan target interaksi minimum setinggi 44px. Gunakan label jelas; jangan mengandalkan warna, hover, atau ikon saja untuk menyampaikan aksi.

Hindari angka, testimoni, klaim pasar, dan copy promosi yang tidak dapat dibuktikan. Ganti konten contoh sebelum rilis.
