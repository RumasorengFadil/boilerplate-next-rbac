# Arsitektur

`src/app/` memakai App Router: `(public)` untuk halaman terbuka, `(auth)` untuk login/register, dan `(dashboard)` untuk area terlindungi. Halaman server membaca database secara langsung; komponen interaktif diberi `"use client"` dan diletakkan sedekat mungkin dengan UI yang memerlukannya.

`src/features/` memegang domain. `src/lib/` adalah infrastruktur lintas domain (database, session, permission, helper). `src/server/` menyediakan guard otorisasi. `src/context/providers/` menampung provider global. Root layout memasang query client dan toast.

Alur akses: proxy mengecek cookie untuk redirect cepat → dashboard layout menjalankan `requireUser` → page/action yang butuh kemampuan tertentu menjalankan `requirePermission` → fungsi akses database menjalankan query dengan scope user bila diperlukan. Jangan hilangkan tahap terakhir: role admin dan member mempunyai scope proyek berbeda.

Public product reads berada di `features/products/public-data.ts`/service: DB-only eligible collection dan ProductRoute resolver. Request-scoped memoization menyatukan list/schema serta detail/metadata. Page detail guard selesai sebelum render/redirect; public presentation memakai Ringkasan, localized features/readiness/CTA/cover. Website SEO builder/schema/OG/sitemap mereuse hasil eligible. Database/permissions/private cover unchanged; persistent product payload cache dan streaming optimization tetap Task6. Tidak ada auto-seed/GET writes/fallback statis produk. Lihat [Products](../features/products.md).

SEO publik berada di `src/features/website/seo/`: registry bilingual, metadata/canonical builders, resolver konten published server-only, JSON-LD aman dan renderer OG Node. Halaman public ID/EN termasuk detail menggunakan bundle metadata/schema bersama; public layout memuat Organization/WebSite sekali. Endpoint read-only `opengraph-image/main/route.ts` menyediakan URL PNG stabil. React cache hanya menyatukan query konten published per request RSC, bukan cache publikasi lintas request. Sitemap dynamic membaca semua detail eligible dan berbagi origin/alternates dengan metadata. Proxy meneruskan locale dari URL (menimpa header inbound), root async membaca/validasi header untuk lang; Header menyinkronkan lang saat navigasi client. Konsekuensi headers() di root: halaman menjadi request-rendered, tanpa duplikasi root layout. Lihat [Public SEO](../features/seo.md) untuk kontrak dan status implementasi.
